# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Autobarn is a sample used-car sales site built on ASP.NET Core (.NET 10). The solution lives in `Autobarn/` and has two projects: `Autobarn.Data` (EF Core entities, DbContext, sample data) and `Autobarn.Website` (MVC website plus a hypermedia JSON API).

## Commands

Run these from `Autobarn/`:

```sh
dotnet build Autobarn.slnx
dotnet run --project Autobarn.Website          # http://localhost:5000 (https profile adds :5001)
```

- There is no test project yet.
- The API reference UI (Scalar) is at `/scalar/v1` and the OpenAPI document is at `/openapi/v1.json`.

## Architecture

**Database is in-memory and reseeded on every start.** `Program.cs` opens a shared-cache in-memory SQLite database (`Data Source=autobarn;Mode=Memory;Cache=Shared`) and keeps one connection open for the whole app lifetime so the database isn't discarded. It then calls `EnsureCreatedAsync()`. There are no migrations. Changes to entities or the model take effect on the next run, and any data written at runtime is lost when the app stops.

**Sample data** comes from CSV files in `Autobarn.Data/Sample/`, embedded into the assembly and read via `EmbeddedResource`:
- Makes and models are seeded with `HasData` in `OnModelCreating`.
- Vehicles are seeded with `UseSeeding`/`UseAsyncSeeding` in `OnConfiguring`, and only when the table is empty.

The CSVs are parsed by splitting on commas, so values can't contain commas or quotes.

**Keys are string codes, not numeric IDs:**
- `VehicleMake.Code` looks like `nissan`.
- `VehicleModel.Code` includes the make prefix, e.g. `nissan-note`. Its computed `ModelCode` property drops the prefix (`note`).
- `Vehicle.Registration` is the key for vehicles.

SQLite string columns use `NOCASE` collation. Navigation collections are marked `[JsonIgnore]` so entities don't serialize cycles.

**Two presentation layers share the same DbContext:**
- **MVC** (`Controllers/`, `Views/`) uses the conventional `{controller}/{action}/{id?}` route. A global `AutoValidateAntiforgeryTokenAttribute` is registered, so every MVC POST needs an antiforgery token. Form input goes through DTOs in `Models/` (e.g. `VehicleDto`, which normalises registrations to uppercase alphanumerics). `RegistrationYearAttribute` handles both server-side and client-side validation.
- **API** (`Api/`) is built from Minimal API endpoints in `AutobarnApi.MapAutobarnApi`, mounted at `/api`. It returns HAL-style resources rather than entities:
  - Every resource record in `Api/Resources/Resources.cs` derives from `Resource`, which serializes a `_links` dictionary first.
  - Links are generated by endpoint name through `LinkGenerator`, using the constants in `Endpoints.cs`.
  - Entity-to-resource mapping plus link construction live in `HypermediaExtensions.ToResource(...)`.
  - Collection endpoints take `index`/`count` query parameters (`count` is capped at 100, validated via `AddValidation()`). They return `ResourceList<T>` with `self/first/last/next/prev` links built by `Paginate`.
  - API URLs use the short model code: `/api/makes/{make}/models/{model}` maps to `Code == $"{make}-{model}"`.

  To add an API endpoint:
  1. Add a name constant to `Endpoints`.
  2. Map it with `.WithName(...)`, `.WithSummary(...)` and `.WithDescription(...)`.
  3. Return `TypedResults` so the OpenAPI output stays accurate.
  4. Add links to it from related resources in `HypermediaExtensions`.

XML doc comments on entities and resource records feed the OpenAPI descriptions (`GenerateDocumentationFile` is on, and CS1591 is suppressed).

## Conventions

- NuGet versions are managed centrally in `Directory.Packages.props`, so `PackageReference` entries have no `Version`. `TargetFramework`, nullable and implicit usings are set in `Directory.Build.props`.
- `.editorconfig`: tabs (width 2), LF line endings, K&R braces on the same line (`csharp_new_line_before_open_brace = none`), `var` preferred, max line length 140.
- The code favours primary constructors for DI (e.g. `VehiclesController(AutobarnDbContext db)`), expression-bodied members, and `SCREAMING_CASE` for constants.
